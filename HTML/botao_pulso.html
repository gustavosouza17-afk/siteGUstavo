Botão de Pulso

Dispositivo de comando momentâneo para controle de circuitos elétricos

O que é um Botão de Pulso?

O botão de pulso (ou botoeira pulsadora) é um dispositivo de comando utilizado para enviar um sinal elétrico apenas enquanto está sendo pressionado. Quando o operador solta o botão, ele retorna automaticamente à posição original por meio de uma mola interna.

Características Principais

  • ✓ Atua momentaneamente no circuito
  • ✓ Não permanece acionado após ser pressionado
  • ✓ Retorno automático por mola interna
  • ✓ Muito utilizado em comandos elétricos

Tipos Principais

Normalmente Aberto (NA)

O circuito fica aberto e fecha quando o botão é pressionado

Normalmente Fechado (NF)

O circuito fica fechado e abre quando o botão é pressionado

🌈 Cores Padronizadas

  • 🟢 Verde: Ligar/Iniciar
  • 🔴 Vermelho: Parar/Desligar
  • 🟡 Amarelo: Atenção ou função especial
  • ⚫ Preto/Branco: Funções gerais de comando

Principais Aplicações

  • ✓ Partida de motores elétricos
  • ✓ Parada de máquinas
  • ✓ Acionamento de campainhas
  • ✓ Controle de elevadores
  • ✓ Sistemas automatizados industriais

Exemplo Prático

Em um circuito de acionamento de motor:

✓ O botão verde (NA) envia o comando de partida para o contator
✓ O botão vermelho (NF) interrompe o circuito de comando e desliga o motor

O botão de pulso é um dos componentes mais básicos e importantes dos sistemas de comando elétrico, permitindo que o operador controle máquinas e equipamentos de forma simples e segura.
