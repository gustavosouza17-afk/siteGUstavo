Chave Manopla

Dispositivo de comando manual para seleção de circuitos elétricos

O que é uma Chave Manopla?

A chave manopla é um dispositivo de comando elétrico acionado manualmente por uma alavanca ou manopla giratória. Diferentemente do botão de pulso, ela pode permanecer na posição selecionada até que o operador a mude novamente.

Características Principais

  • ✓ Permite abrir, fechar ou selecionar circuitos elétricos
  • ✓ Mantém sua posição após o acionamento
  • ✓ Muito utilizada em painéis de comando
  • ✓ Fácil operação manual

Tipos Disponíveis

2 Posições

Liga/Desliga (0-1)
Simples e direto

3 Posições

Esquerda-0-Direita
ou Manual-0-Automático

Com Retorno

Retorna automaticamente à posição inicial por mola

Aplicações Industriais

  • ✓ Comando de motores elétricos
  • ✓ Seleção entre modo manual e automático
  • ✓ Reversão do sentido de rotação
  • ✓ Controle de máquinas e equipamentos
  • ✓ Seleção de funções em painéis

✨ Vantagens

  • ✓ Fácil operação
  • ✓ Boa durabilidade
  • ✓ Permite múltiplos modos de funcionamento
  • ✓ Ocupa pouco espaço em painéis
  • ✓ Feedback visual da posição

Diferença entre Botão de Pulso e Chave Manopla

Botão de Pulso: Atua apenas enquanto é pressionado
Chave Manopla: Permanece na posição escolhida até novo acionamento
